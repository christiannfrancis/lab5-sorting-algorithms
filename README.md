### Project Overview: 

This project implements and analyzes six different sorting algorithms in C++. The goal is to understand how different sorting techniques work, compare their time complexities, and evaluate their performance when sorting numerical data. The project includes three elementary sorting algorithms and three more efficient sorting algorithms. Each team member is responsible for implementing two algorithms. The program reads numerical data from an input text file, sorts the data using the implemented algorithms, and outputs the sorted results. Execution times can also be measured and compared to analyze the performance of each algorithm.

### Elementary Sorting Algorithms: 

Insertion Sort: Builds a sorted portion of the array by inserting each new element into its correct position.
Bubble Sort: Repeatedly compares adjacent elements and swaps them when they are in the incorrect order.
Selection Sort: Repeatedly finds the smallest element in the unsorted portion and places it in its correct position.

### Efficient Sorting Algorithms: 

Heap Sort: Uses a binary heap data structure to repeatedly extract the largest element and build a sorted array.
Merge Sort: Uses a divide-and-conquer approach to split the array into smaller portions, sort them, and merge them back together.
Quick Sort: Uses a pivot element to partition the array into smaller sections, which are then sorted recursively.
